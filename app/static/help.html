Bursar Cashbook Help

Phase 6 local pilot: the bursar's registered workbook is the live destination.

Starting the application

Double-click START CASHBOOK.bat and keep that window open. The browser interface will open automatically.

1. Register the live cashbook

Choose the actual `.xls` workbook the bursar normally captures into. The application parses its monthly PC/RC sheets and category columns, stores that workbook as the managed live cashbook, and writes approved transactions into that same file.

No second cashbook is generated.

2. Import a Standard Bank statement

Upload CSV, XLS or XLSX. The application validates transaction structure, detects duplicates, and reconciles the running balances before accepting the statement.

3. Review exceptions

Trusted exact historical classifications are approved automatically. New, fuzzy or uncertain classifications appear in the review table. Saving a classification immediately attempts to sync that transaction into the live cashbook.

4. Check the cashbook

Use Live cashbook preview to see the target sheet, category and sync state. Click Open cashbook in Excel when you want to inspect the actual workbook.

If Excel already has the workbook open while the app needs to write, close Excel and click Sync cashbook now.

Safety

Imported bank transactions are fingerprinted. Synchronized cashbook rows are tracked separately, so retrying sync cannot append the same transaction again. If an already-synced category is corrected, the original row is reallocated rather than duplicated. A cashbook backup is created before each write.

If something goes wrong

Look for an error ID such as ERR-20260831-12AB34CD. Download the support bundle and send both to the developer.
