Bursar Cashbook Help

Short guide for the Standard Bank pilot.

Starting the cashbook

Double-click START CASHBOOK.bat. Keep the black Cashbook window open while you work. Your browser will open the local cashbook automatically.

1. Import a statement

Download the Standard Bank statement as CSV, XLS or XLSX. Choose it under Import statement. The cashbook will validate the transaction structure and running balances before anything is saved.

If reconciliation fails, do not continue with that statement. Download a support bundle and contact the developer.

2. Review transactions

Every new transaction remains pending until you select or approve its category. Debit transactions use expense categories; credits use income categories.

3. Export

Select the financial year and choose the export you need. A confirmation screen shows transaction totals, money in/out, pending reviews and reconciliation status. The export button stays disabled until the year is ready.

If something goes wrong

Look for an error ID such as ERR-20260831-12AB34CD. Return to the cashbook and click Download support bundle. Send the ZIP and the error ID to the developer. The support bundle excludes full transaction descriptions and bank references.

Backups

The app automatically creates backups. You can also create one manually. Restore only when instructed or when you intentionally need to return to an earlier state. A new safety backup is created before every restore.

Pilot rule

During the pilot, compare generated WCED outputs with the normal manual process before treating the generated workbook as final.
