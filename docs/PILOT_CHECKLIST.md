# Installed Application Pilot Checklist

- [ ] Install `BursarCashbook-Setup.exe` and open **Bursar Cashbook** from the Desktop shortcut.
- [ ] Confirm the browser opens automatically and no terminal window is shown.

- [ ] Register a copy of the bursar's actual current cashbook.
- [ ] Confirm all monthly PC and RC sheets are detected.
- [ ] Import a known Standard Bank statement already captured manually elsewhere.
- [ ] Confirm reconciliation difference is R0.00.
- [ ] Compare auto-approved categories against the manual capture.
- [ ] Review all exceptions.
- [ ] Open the live cashbook and compare every populated row for the pilot statement.
- [ ] Run **Sync cashbook now** twice and confirm no rows are duplicated.
- [ ] Correct one already-synced transaction and confirm the original row is reallocated rather than duplicated.
- [ ] Confirm a `cashbook_backups/` file exists before each live sync.
- [ ] Test with the workbook open in Excel and confirm the app blocks safely and can retry after Excel closes.
- [ ] Save the support bundle from the pilot session.
